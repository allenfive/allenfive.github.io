## Overview

Vibe Coding Detector - by A5 is a Chrome extension that helps you determine whether a website was likely created using AI or automated site-generation tools. It analyzes real, concrete signals in a page's code, structure, metadata, and visible text to estimate how likely the site was "vibe coded."

Built for developers, researchers, and curious builders who want explainable results, not black-box guesses.

## Key Features

- **AI-generation detection**: Identify signals commonly associated with AI- or template-generated websites
- **Clear verdicts**: Get a Likely, Unclear, or Unlikely determination
- **Confidence scoring**: See a 0-100% confidence score for each analysis
- **Explainable reasons**: Understand exactly which indicators were detected
- **Debug breakdown**: Optional detailed view of matched rules and scoring
- **Local analysis**: Runs entirely in your browser with no cloud uploads
- **Read-only inspection**: Never modifies page content or behavior

## How It Works

1. Install the Vibe Coding Detector extension from the Chrome Web Store
2. Navigate to any public website
3. Click the extension icon and select Analyze
4. The extension examines page structure, code patterns, metadata, and visible text
5. Review the verdict, confidence score, and reasons
6. (Optional) Expand the debug breakdown for deeper inspection
