## Overview

Coin Collector Assistant - by A5 is a Chrome extension that helps you save eBay coin listing snapshots, build your collection library, and export your data to CSV. Perfect for coin collectors who want to organize and track their collection.

## Key Features

- **Save eBay snapshots**: Capture and save coin listing information from eBay
- **Build collection library**: Organize your coin collection in one place
- **CSV export**: Export your collection data to CSV format
- **Free tier**: Get started with 10 snapshots at no cost
- **Pro tier**: Unlimited snapshots plus CSV export capability
- **Simple interface**: Clean, intuitive Chrome extension interface

## How It Works

1. Install the Coin Collector Assistant extension from the Chrome Web Store
2. Navigate to any eBay coin listing page
3. Click the extension to capture the listing snapshot
4. Build your collection library by saving snapshots
5. Export your collection to CSV for backup or analysis (Pro feature)
